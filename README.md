# Sistema Bancário em Java
Projeto de Simulação de operações bancárias desenvolvido em Java para consolidação dos conceitos fundamentais da **Programação Orientada a Objetos (POO)**.
---
## Tecnologias Utilizadas

* **Linguagem:** Java
* **IDE:** Intellij IDEA e Sublime Text
* **Controle de Versão:** GitHub

---
##  Conceitos de POO Aplicados 

* **Encapsulamento:** proteção dos atributos utilizando o modificador "private" com acesso controlado por métodos getters.
* **Construtores:** Inicialização segura do estado do objeto com parâmetros obrigatórios.
* **Regras de Negócio** Validação das operações de depósito e saque para evitar valores inválidos ou saque sem saldo suficiente.

---
## Como Executar o Projeto

1- Faça o download ou clone o repositório.
2- Abra o projeto na sua IDE java
3- Execute a classe "Main.java".
